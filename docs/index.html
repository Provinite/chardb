CharDB

A modern character hosting platform for creative communities. Organize characters, manage species, and build vibrant creative spaces.

Platform Features

🎨

Character Profiles

Rich character profiles with custom traits, galleries, and detailed information pages.

🌿

Species Management

Create and manage species with variants, traits, and customizable attributes.

👥

Community Tools

Role-based permissions, member management, and community-specific settings.

🖼️

Media Galleries

Upload and organize artwork with support for multiple image formats and galleries.

🔒

Content Moderation

Built-in moderation queue for reviewing uploaded content before publication.

🎁

Item System

Create custom items and manage community inventories with Discord integration.

📜

Item Ledger

Every item movement is recorded — who moved it, to whom, and why. Each item's history is public within its community.
