Creating a Character

From a picture to a profile

0

Overview

A character in CharDB belongs to a species in a community. You make one from the community it belongs to, on a single form: its picture, its name, its species and rarity, its traits, and how it is shown and offered to others.

The picture comes first. It is hard to describe a character you cannot see, so the form keeps the picture in view while you fill in everything else.

1

Finding the Form

Open the community the character belongs to and choose Create Character in the top bar. The form opens with the picture in its own column on the left and everything else on the right.

On a narrow screen, such as a phone, the picture moves above the form instead of beside it.

The create form, before anything is filled in
2

Picking the Picture

Click the drop zone or drag a file onto it. JPEG, PNG, WebP and GIF files up to 10 MB are accepted. The picture shows straight away; Remove image takes it off so you can choose another.

Nothing is uploaded yet. The picture waits on the form until you create the character, and is uploaded then.

Sensitive Content marks the picture as sensitive and asks for a short description. Sensitive uploads are not accepted at the moment, so ticking it stops the form from submitting until you untick it or remove the picture.

No picture option? Some communities do not let every role upload character images. Once you pick a species in one of those, the picture panel says so instead of offering a drop zone, and any picture you had chosen is removed.
A picture chosen, ready to go
3

Filling in the Rest

The rest of the form runs top to bottom. On a wide screen the picture stays pinned beside it as you scroll, so the character is in view while you choose its traits.

  • Basic Information – the name, and any custom fields you want to add.
  • Species and variant – required. You can only choose species you are allowed to make characters in.
  • Ownership – only shown to staff who may make characters for someone else or leave them unowned. Everyone else's characters are their own.
  • Traits – whatever the species asks for. Some rarities allow more than one set; see Character Forms.
  • Details, settings and tags – the write-up, who can see the character, whether it is open to trades or offers, and tags to help people find it.
Scrolled down to the traits, with the picture still in view
4

Creating It

Create Character makes the character, uploads the picture to it, and sets the picture as its main image, then takes you to the new character.

The picture goes to the community's moderators like any other upload. Until one approves it, the character shows a pending moderation placeholder where the picture will be. The picture has the same visibility as the character, so a private character's picture is private too.

Straight after creating: the picture is waiting on a moderator
Once approved, it is the main image
5

If the Picture Does Not Attach

The character is made first and the picture second, so a problem with the picture never costs you the character. If the upload fails, the character is still created and you still land on it.

A message says the picture could not be attached, with an Upload it again link. That opens the upload page with the character already chosen; see Uploading Images.

The character is made; the picture can be uploaded again
6

Changing the Picture Later

Edit Character shows the current main image in the same column, so you can see the character while you edit it. Upload a new image opens the upload page for this character.

A new upload does not replace the main image on its own. To make a different picture the main one, use Set as Main on it in the gallery on the character's page.
